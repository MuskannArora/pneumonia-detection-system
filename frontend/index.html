Model details & reported evaluation

Architecture (read from the saved model)

  • Input 224 × 224 × 3, pixel range 0–255 (rescaling is built into EfficientNetB0)
  • EfficientNetB0 backbone, ImageNet initialised
  • Channel attention: average- and max-pooled descriptors through a shared MLP, sigmoid gating
  • Spatial attention: channel-wise mean and max, 7 × 7 convolution, sigmoid gating
  • Head: GAP → BatchNorm → Dense 256 → Dropout 0.4 → Dense 64 → Dropout 0.3 → Dense 1 (sigmoid)
  • Decision rule: pneumonia probability ≥ 0.55 → Pneumonia
